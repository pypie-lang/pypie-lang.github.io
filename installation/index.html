Install PyPie

Dependencies

- Python >=3.12
- Linux or Apple Silicon
- [Optional] Python >=3.14, to avoid writing from __future__ import annotations in every file

Install PyPie

pip install -U pypie-lang

To run on CUDA 13:

pip install -U "pypie-lang[cuda13]"

To run on CUDA 12:

pip install -U "pypie-lang[cuda12]"

IDE Support

PyPie's vscode extension is available.
